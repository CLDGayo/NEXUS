# Avatar & Branding

Workspaces support a custom avatar image displayed in the UI sidebar and workspace switcher. Avatars are stored in MinIO and served via presigned CDN URLs.

---

## Prerequisites

- MinIO configured: `MINIO_ENDPOINT`, `MINIO_ACCESS_KEY`, `MINIO_SECRET_KEY`, `MINIO_BUCKET_AVATARS`, `MINIO_PUBLIC_BASE_URL`
- Caller has `admin` or `owner` role

> **📝 NOTE:** Avatar upload fails gracefully if MinIO is not configured — the API returns a `503` with a descriptive message rather than a 500.

---

## Upload a Workspace Avatar

```http
POST /api/tenants/{tenant_id}/avatar
Authorization: Bearer <manager-jwt>
Content-Type: multipart/form-data

file=@workspace-logo.webp
```

**Format requirements:**

| Property | Requirement |
|---|---|
| Format | WebP only |
| Max size | 5 MB |
| Dimensions | Any — the UI renders at 40×40px in the sidebar |

The server validates the WebP format using Pillow before storing. Non-WebP files return `400 Bad Request`.

**Response:**

```json
{
  "avatar_url": "https://assets.nexus.gayo-sphere.cloud/nexus-avatars/acme-corp/avatar.webp",
  "updated_at": "2026-06-13T00:00:00Z"
}
```

The `avatar_url` is stored in `app.tenants.avatar_url` and returned in all workspace detail responses.

---

## Remove a Workspace Avatar

```http
DELETE /api/tenants/{tenant_id}/avatar
Authorization: Bearer <manager-jwt>
```

Deletes the object from MinIO and sets `app.tenants.avatar_url = NULL`. Returns `204 No Content`.

---

## MinIO Storage Path

Avatars are stored at:
```
{MINIO_BUCKET_AVATARS}/{tenant_slug}/avatar.webp
```

Example: `nexus-avatars/acme-corp/avatar.webp`

The same filename is reused on each upload — no versioning. The previous avatar is overwritten.

---

## Presigned URLs

`avatar_url` in the workspace response is a presigned URL generated by MinIO. It includes a time-limited signature for authenticated access to the private bucket.

**URL lifetime:** 24 hours (configurable via MinIO policy). The UI re-fetches workspace data periodically to refresh expired presigned URLs.

> **⚠️ WARNING:** Do not cache `avatar_url` for more than 24 hours — presigned URLs expire and return `403 Forbidden` from MinIO after expiry.

---

## User Profile Avatars

User profile avatars (not workspace avatars) follow the same pattern:

```http
POST /api/me/avatar          # Upload user avatar
DELETE /api/me/avatar        # Remove user avatar
GET /api/me/avatar/url       # Get fresh presigned URL
```

Stored at: `{MINIO_BUCKET_AVATARS}/users/{user_id}/avatar.webp`

---

## Troubleshooting

| Symptom | Cause | Fix |
|---|---|---|
| `503 Object storage unavailable` | MinIO not configured or unreachable | Check MinIO env vars and container health |
| `400 Invalid image format` | Non-WebP file uploaded | Convert image to WebP before uploading |
| Avatar shows broken image | Presigned URL expired | Refresh workspace data; UI re-generates URL |
| Avatar not updating | Browser cache | Hard-refresh (`Cmd+Shift+R`) |
